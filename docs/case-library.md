# 九案例适配说明

版本0.4.2。用户提供的`案例库/`九例已接入独立工作台与iframe宿主。用户确认：O0008以CAM原程序和图纸为主。原95个资料文件按字节保留，未删除、改写程序行或把不支持指令当作空操作。

## 使用

打开[工作台](http://127.0.0.1:8786/)，在顶部“案例库”选择编号后点“载入案例”。展开“参数与原始资料”查看毛坯、H/D表、来源冲突、假设和PDF/图片；点“任务配置”编辑完整Job。上位网页在“联调案例”选择后点“下发案例”，使用同一任务和原文本。

默认保留原F/S和碰撞检查，并使用“提示并继续动画”。当前九例均可完成动画，O0008/O0020/O0021/O0315的原风险保留为独立提示，不能把完成等同无碰撞。O0008实际完成至M30/物理行134，保留第95、119、122、123行共4条提示，见[浏览器证据](collision-warning-evidence.json)。提示模式逐Instruction记录首次接触，不穷举同段所有接触；O0022的F20可用倍率或源行单步查看。

“碰撞处理→碰撞即暂停→应用设置”恢复原来的首触停机行为。下文结果表及早期JSON/截图是0.4.0暂停模式记录；该模式继续作为回归测试保留。新模式的说明见[碰撞提示与连续动画](collision-warning.md)。

8份STL是成品参考，以半透明线框显示；初始毛坯另行配置。O0025没有STL，使用原PDF/图示。STEP/TOP/DFT保留在原资料归档，不宣称浏览器解析它们。构建自动携带使用的STL/PDF/图片，部署无需访问本机F盘。

## 已实现语义

| 指令或几何 | 实现 |
| --- | --- |
| G41/G42/D/G40 | D采用半径mm，独立于刀具号。XY直线/圆弧真实刀心偏置，凹角求交修剪、凸角圆弧连接，线性引入/引出；补偿后重算弧长、时间和轴端点。 |
| G15/G16 | G90下X半径、Y角度；省略半径按当前名义位置保持，角度不作英寸缩放。G15恢复XY。G91极坐标、与G81混用明确拒绝。 |
| G81/G80/G98/G99 | 按当前固定刀轴展开定位、R面、进给、退刀；G90/G91孔位，保存循环面，默认G98；G0/G1/G2/G3及参考返回取消循环。各子动作继承当前源行。 |
| G92 | 设定当前位置读数，无几何移动；后续运动携带G92有效原点供碰撞工件坐标反算。 |
| G28/G30 | 经编程中间点返回显式配置的第一/第二参考轴点，仅作用给定轴；不等于工作原点。 |
| G4 X | 本方言按秒停留，与P二选一，不产生X运动。 |
| 相对H表 | 有效H=表值+toolLengthReferenceMm，支持截图的负差值；G43/G49其余约定见README。 |
| Y侧头 | 刀尖至刀柄方向-Y，沿+Y钻进；材料真截面/有限刃长、刃/杆/柄凸体、显示共同旋转。非轴向侧切明确拒绝。 |
| 成形刀 | 用户输入单调分段径向剖面，真实逆剖面决定材料下包络；支持等Z XY及纯Z切削，混合斜向拒绝。碰撞用包围凸包，命中标potential/unknown。 |

运动语义参考[LinuxCNC官方指令文档](https://linuxcnc.org/docs/html/gcode/g-code.html)及[刀补说明](https://www.linuxcnc.org/docs/2.8/html/gcode/tool-compensation.html)，结合本项目已明确的方言约定。G16及侧头是案例方言适配，不能据这些参考宣称兼容所有厂商控制器。
