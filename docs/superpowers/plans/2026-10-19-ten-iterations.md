# 十轮联调与仿真交付改进计划

> 执行方式：superpowers:executing-plans，由主代理连续实施，完成后一次独立审阅。用户已明确要求“自行做10次迭代更新”，按该授权直接确定范围并推进，不追加逐轮审批。

**Goal:** 让现有网页机床仿真更适合交给第三方上位网页开发者接入，保留碰撞提示后完整播放、真实尺寸换刀与现有案例行为。

**Architecture:** 保持 iframe/postMessage 1.0、Worker 几何与 Vue/Three.js 工作台。对现有适配器、联调页和导出流程作有界改进，不改控制器方言或扩张碰撞覆盖。

**Tech Stack:** Vue 3、Three.js、TypeScript、Vite、Vitest、Playwright Edge；不增加运行依赖。

**Spec:** 本计划同时记录有界设计；依据已实现的通讯手册、碰撞提示规则及用户自主迭代授权。

## 约束与审阅重点

- 协议保持 cnc-sim/1.0；旧任务省略 stopOnCollision 仍默认暂停，案例显式 false。
- 每轮先复现相应问题或缺少的行为，再实现、验证、单独提交；最终全量回归。
- SDK不自动重放有副作用的失败控制命令；晚到事件、重复事件和卸载不得跨运行污染状态。
- 明确处理保存失败、持久化降级、回调异常、iframe重载和连续RESET/SEEK。
- 模型追加不能丢失既有夹具/毛坯；CSV保留原始源行、坐标和不确定性。
- 只发布到已授权的 ACTION/cnc-web；远端变动用期望SHA保护，不覆盖他人更新。

## 十轮任务与验收

每轮共同步骤：增加下列失败测试 → 运行确认失败 → 实现指定接口 → 相应测试通过 → 更新记录并提交。

| 轮次 | 交付与文件 | 核心验收 |
| --- | --- | --- |
| 01 | SDK输入校验，examples/host-integration/cnc-sim-client.js，tests/host-sdk.test.ts | 无效身份/倍率/超时/重试/不可克隆对象不发送、不遗留pending；断连load不改身份 |
| 02 | SDK释放与异步隔离，同上 | dispose幂等；保存中的事件完成后不再ACK/回调；释放后不能重连 |
| 03 | SDK握手与重连，同上及示例页 | connect返回一致信封；重载重新握手有超时；连接变化可显示 |
| 04 | SDK串行控制，同上及真实iframe测试 | 连续RESET→调速/SEEK使用新身份；失败不毒化后续操作；排队任务不跨重载 |
| 05 | SDK事件降级与回调隔离，同上 | 无eventId的ERROR可被业务接收；durable:false明确提示；回调异常不破坏其他消息处理 |
| 06 | 联调页资源与消息校验，src/Host.vue | URL模型追加保留案例模型；完整协议版本校验；iframe刷新清除就绪并重新握手 |

| 08 | 碰撞CSV导出，src/lib/incidentExport.ts、App.vue | 全部事件源行/N号/对象/机床工件坐标/误差可导出；CSV特殊字符与公式文本安全 |
| 09 | 生产构建包含接入示例，vite.config.ts及示例入口 | dist含示例；预览环境可加载任务JSON与仿真页并完成运行 |
| 10 | 0.5.0交付一致性、SDK类型、手册与更新记录 | 握手/报告/页脚版本统一；第三方TypeScript可用；全单元、Edge及构建通过，GitHub发布校验 |
