# 用户案例库适配设计

用户要求：至少适配cnc-web/案例库全部九个案例。成功标准是网页选择原案例、载入原始程序和已有STL/图纸，按参数表实际切削/换刀/补偿并保留原物理行；原程序风险应正确停机，不以禁用碰撞或改写G代码伪造成功。

这是既有解释器、材料与网页案例入口的扩展，包含新运动语义及固定侧头工具。保持Worker唯一执行状态、连续路径检查和来源绑定。原始案例95个文件只读，不覆盖。STEP/DFT/TOP不解析，已有STL用于目标参考，图纸用于确定毛坯与工具参数。资料不足的参数在每例清单标明假设，可由完整JSON修改。

方案选择：保留原始G代码，由解释器展开循环/极坐标/回参考点，半径补偿在运动IR上执行前瞻几何偏置。相比预先改写案例能保持语义和物理行，后续同类程序也受益；相比引入外部控制器/WASM不增加不可用运行依赖。

新增：G41/G42/D半径表与G40、G15/G16、G81/G80/G98/G99、G92、G28/G30、G4 X秒。半径补偿支持XY直线/圆弧及进入退出，凹角求偏置交点、凸角圆角衔接，无法实现的过切/短段拒绝。原控制器差异与进退约定必须明确，不冒充厂商认证。补偿后重新计算长度/时间/轴端点，碰撞和材料消费同一刀心轨迹。

O0001使用原文(@4 Y+)侧钻，增加固定Y侧头的钻孔运动与真实刀形朝向/体积，保持三轴平移，不加入联动旋转轴。H仍是安装Z量规补偿，侧头安装需单独标定；不支持任意倾斜钻削时明确拒绝。

案例入口：与十个故障教学示例分开列出九个原案例；每例显示毛坯、刀/H/D、来源/假设，提供程序/参考模型与图纸链接，宿主可下发同一Job。构建输出包含所需原程序/STL/图纸，不将开发盘绝对路径暴露到部署。

验证：新指令和刀补几何解析真值、侧孔截面、九个原文本逐例校验/执行、碰撞源行及循环内部动作、真实Edge工作台和iframe；原222单元/16浏览器回归。原代码中的G0入料、不可达补偿或存量碰撞保留为实际结果并说明。阶段结论必须区分“可解释/可模拟”和“原程序通过碰撞检查”。
