# 上位机接口手册交付记录

2026-10-18，适用软件版本 0.4.2，协议 cnc-sim / 1.0。

用户要求撰写上位机通讯接口手册。以实际 ProtocolSession、attachEmbed、任务校验、碰撞字段、可靠事件存储和 App.vue 报告实现为依据，编写[完整手册](上位机通讯接口手册.md)，提供[纯网页示例与参考适配器](../examples/host-integration/index.html)以及[双刀任务](../examples/host-integration/sample-job.json)。README 与上级开发文档增加入口。

手册覆盖 iframe/来源校验、消息信封、全部命令与应答、Job/刀具/模型/机床配置、状态与换刀动画、碰撞原始物理行/N号/SHA、M/工件坐标和误差、提示后继续、ACK/去重/重试、RESET/SEEK新runId、中断档案、报告及生产部署。明确区分 COMPLETED 与 fully_checked、PROGRESS 直接快照与 STATE 的嵌套快照；示例目录不默认进入 dist。

## 核对过程中修复

1. HELLO 报告 engineVersion 硬编码为 0.3.0，与当前 0.4.2 不符。新增版本一致性测试先观察失败，再改为读取 package.json 版本；单元回归通过。
2. Host.vue 原按“含 eventId”确认消息，导致 EVENT_ACK 的 COMMAND_ACK 被再次确认。真实浏览器先观察 250ms 内出现 11129 条确认应答；修为只确认关键事件类型后对应测试仅有 1 条确认应答。
3. 独立只读审阅发现参考适配器在 RESET/SEEK 应答丢失后不能从 STALE_RUN 恢复身份。新增真实 iframe 测试先观察“任务版本已失效”，再采纳错误信封的当前身份。默认状态/报告查询自动重新读取一次，显式历史查询仍拒绝，控制命令不自动重放。错误对象提供 identity。

审阅按 requesting-code-review 技能安排，覆盖手册与源代码一致性及参考适配器。1 项 P2 已由主代理修复并用回归验证；没有请求第二轮审阅，也不把初次审阅称为最终代码复审。

## 验证范围
