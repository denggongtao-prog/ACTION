# 0.4.1 换刀动画交付记录

用户先要求换刀动画，随后指出初版刀库过于简陋，要求参考开源/实物结构并考虑刀具与刀库实际大小。本轮保留换刀执行语义，重做渲染结构和尺寸规则。

## 实现

- Worker 将不同刀号 M6 展开为4秒教学交换，沿用已配置接近/返回XYZ；暂停、恢复、倍率、重置与源行单步一致。新刀夹紧碰撞检查通过后才回传 TOOL_CHANGE；碰撞仍关联原M6源行。
- 参考 Haas 伞形刀库原厂图、XATC 圆盘方案和 Avid 装配净空说明，自行绘制刀盘、工位刀套、立轴驱动座、双滑轨、支架及主轴接收腔。资料与尺寸公式见 tool-exchange.md，没有复制开源资产或代码。
- 工位不少于8，按完整刀具最大直径、4mm刀套壁余量、0.35mm倒角和10mm净距计算分布半径。演示刀盘外廓Ø158.7mm。实际显示刀径、伸出/总长和刀柄直径长度，不缩放工具凑画面。
- 工具统一由 ToolModel 生成，保留球头、钻尖、成形剖面及固定侧轴。移除超包络圆帽与刀尖圆球。侧头使用单独装卸示意，不冒充普通竖直自动刀套。
- 三维机构视角自动取景，结束恢复加工视角；尺寸与阶段栏位于画布下方，避免窄屏遮挡。增加双刀演示场景，原九例文本不改。

## 验证过程

1. M6时长、暂停/倍率/单步、同刀/预选与夹紧回传先写失败回归，再接入Worker。旧事件测试原本假设M6瞬时完成，修改推进时间后保持原事件语义断言。浏览器重复换刀测试按20倍速度验证同帧多事件。
2. 装夹碰撞回归最初把初始Z40误当Z30，伸出80的新刀实际停在Z10，未碰材料；修正测试为伸出100后正确触发夹紧碰撞，未修改产品碰撞规则。
3. 工位间距、随刀径扩容与四种工具网格包络测试先因缺模块失败，随后实现。刀套倒角净距检查实际测得9.3mm，修正布局计入两侧倒角后达到10mm。增加阶段边界连续性断言。
4. 独立只读审查一轮，见下；修复之后检查完整单元、浏览器与构建。未为样式改动添加镜像测试。

## 独立审查与处理

审查覆盖 fc0f165 之后未提交候选及新增文件，由 tool_changer_review 一次只读完成；无Critical，提出2项Important，并提前发现1项GPU资源释放问题。

- Sprite工位文字的CanvasTexture/SpriteMaterial曾未被disposeObject释放。真实dispose事件回归先失败，扩展清理Sprite自有纹理与材质后通过；保留Three共享quad。
- 长刀柄侵入主轴实体：150mm刀柄顶到基准+150，旧实体从+128开始。添加真实Mesh包围盒回归，观察失败后让实体起点至少位于完整刀柄顶部+4，接收腔延伸到实体接缝。
- 短刀柄夹持槽不足容纳固定最小厚度刀套：4mm刀柄实际刀套占+0.89..2.59，超过夹持槽。回归先失败，刀套厚度与倒角改为按槽高比例计算后，完整网格落在+0.28h..0.40h范围。

审查放弃评判的事项及处理：厂商装配公差、实机安全没有真实CAD/标定，保留教学范围；装饰机构不纳入当前碰撞coverage，不将显示无穿插当成运动碰撞证明；文档同期补齐，由主代理核对。修复由主代理验证，不把候选审查称为最终代码复审。

## 最终验证

33个文件326项单元测试通过；19项真实Edge端到端通过；TypeScript检查与Vite生产构建通过。1440px桌面和860px窄屏截图已查看，换刀期间暂停进度保持不变、恢复完成、无pageerror和窄屏水平溢出，记录见 tool-exchange-evidence.json。原500kB主包提示仍存在，本轮增加3D机构后主包约770kB（gzip约209kB），未作专项分包优化。

只有已配置的XYZ路径、新刀装夹及原报告对象对进入碰撞检查；换刀机构与4秒周期为教学设计，不表示真实机床节拍或整机认证。所有修改保留本地development，无推送或发布。

## 入口整理

随后根据用户确认，将9个原始案例作为主入口，独立工作台默认载入O0001；换刀演示保留独立按钮，其他10个功能验证样例移入默认折叠的“开发测试”。嵌入模式继续等待上位网页下发，不自动执行本地案例。文件名随载入任务更新，防止换刀演示沿用原案例文件名。

新增真实浏览器回归先因默认仍为O1001失败，修改后覆盖默认O0001、9个正式案例、独立换刀演示、返回真实案例、默认折叠及展开后故障场景。既有功能测试明确通过开发入口选择固定正常样例；性能/冒烟脚本也显式选择相同样例，保持测量对象。最终326项单元、20项Edge端到端及构建通过；默认页和换刀页桌面/窄屏截图已同步。
